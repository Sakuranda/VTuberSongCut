# 2026-10-16 使用体验检查

本轮以新用户的空白工作区开始，使用合成录播和音频验证界面与媒体流程，不修改用户已有的素材与标注。

| 发现的问题 | 调整 |
| --- | --- |
| 一个标注区间的时间、演唱者和操作分散在两行 | 桌面同行排列，演唱者选择限制为 180px；窄屏分两行 |
| 项目名称与主播名称必须重复填写 | 主播名称必填，项目名可选并自动生成 |
| 训练页反复解释流程，成功进度长期占据空间 | 简化标题，标注说明与快捷键按需展开，完成后收起进度 |
| 空白切歌页显示大量暂不可用控件 | 首次打开聚焦导入入口，导入后再显示编辑面板 |
| 已有模型的入口埋在训练页末尾 | 切歌页和训练页提供直达模型库的入口 |
| 切歌上传没有与训练上传一致的反馈 | 共用上传百分比、素材检查状态和失败重试组件 |
| 保存按钮离导出位置太远 | 导出区增加就地保存入口 |
| 未实现功能占位与项目快照干扰主要操作 | 删除宣传式标题和占位卡片，附加导出文件折叠展示 |
| 两个工作区持续轮询，慢请求可能重叠 | 只刷新可见工作区；空闲每 10 秒，有任务时更频繁；后台标签暂停请求，返回立即读取 |
| 已兼容的视频仍完整重编码，小素材被放大 | 优先复制兼容码流，不兼容时才转码；低分辨率不放大 |
| 纯音频无法生成兼容预览 | 支持 AAC 音频预览，带封面的 MP3 不再被误当作视频 |

## 验证范围

- 内置浏览器及 Chrome：新建项目、上传错误与重试、生成预览、标注与保存。
- Chrome：手动切出 5 秒片段，保存后实际导出 MP4 和 MP3。
- 纯音频导入后，视频选项禁用，导出按钮明确显示 MP3。
- Chrome 390px、940px 与桌面宽度：窄屏换行无横向溢出，常规窗口控件保持同行。
- 轮询回归：隐藏/恢复、慢响应不重叠、请求中止、失败重试、任务完成后停止。
- 真实 FFmpeg 素材：多种容器、快速封装、音频转换、封装失败后的实际重编码回退、小视频尺寸及原文件完整性。
- 本轮未重新编译或发布桌面安装包，浏览器验证不等同于三个操作系统上的完整安装验收。

回归检查：后端 142 项通过、1 项可选测试跳过；前端 10 项通过，生产构建成功。

## 预览性能记录

本机 Apple Silicon，10 秒 1080p/30fps H.264 + AAC FLV，同一输入各运行三次：

| 路径 | 耗时中位数 | 预览文件 |
| --- | --- | --- |
| 原先 720p 重编码 | 0.562 秒 | 1.23 MB |
| 复制兼容码流并封装 MP4 | 0.054 秒 | 7.19 MB |

新路径保留原分辨率和码率，节省编码时间，但文件可能更大。此结果是短素材的本机对照，不代表所有长录播或远程播放都有相同倍数的提升；非兼容编码仍需转换。快速封装失败时会明确开始转换阶段，进度随实际处理重新计算。
