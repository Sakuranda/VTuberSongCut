# 外观与皮肤

在顶部点击 **外观**，选择后立即生效，不需要保存项目或刷新页面。

- **猫娘相伴**：黑发绿瞳角色插画，出现在欢迎页、顶部头像和外观设置中。
- **简洁工作台**：收起角色插画，保留相同的编辑功能。
- **主题配色**：翡翠绿、蝴蝶紫、缎带红、经典蓝。
- **明暗模式**：浅色、深色或跟随系统；默认是猫娘相伴、翡翠绿、跟随系统。
- **恢复默认**：只重置外观，不更改项目、模型、标注或导出设置。

偏好保存在当前浏览器的当前站点中。同一站点的多个标签页会同步；换浏览器、域名或端口后需要重新选择。浏览器禁止本地存储时，仍可在本次打开期间换肤。

切换皮肤不重建剪辑或训练工作区，因此未保存草稿和播放位置保持不变。角色插画不覆盖视频、时间轴或标注输入框，也不会进入导出视频；视频和字幕的实际颜色由素材、字幕设置决定。

外观面板支持键盘 Tab 导航、方向键选择和 Escape 关闭。面板打开时，剪辑与训练快捷键暂停响应；关闭后焦点回到入口。小屏面板只滚动选项区域，关闭和完成按钮保持可见。

## 开发约定

- `apps/web/src/theme.ts`：偏好校验、存储、系统明暗与标签页同步。
- `apps/web/src/themes.css`：语义颜色变量、配色和外观面板样式。
- `apps/web/src/AppearanceSettings.tsx`：设置界面；不依赖媒体、模型或训练服务。
- `apps/web/src/SkinWelcome.tsx`：欢迎页和头像；仅调用现有导入与模型入口。
- 新增配色时同步更新 `tests/theme.test.mjs`，检查文字、按钮、边框及错误状态的对比度。
- 不通过滤镜或全局透明度改变视频与字幕；语义状态不能仅靠颜色区分。

角色资产随应用打包，不依赖第三方图片服务。插画由内置图像生成工具参考用户提供的形象重新绘制，[提示词与生成记录](../apps/web/src/assets/skins/README.md)保留在仓库中。
